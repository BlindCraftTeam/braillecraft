Markdown files

BrailleCraft opens Markdown files (.md) as print documents and saves print and braille documents as Markdown. Markdown is the plain-text form many web pages, notes and books are written in: a line starting with one or more number signs is a heading, blank lines separate paragraphs, lines starting with a dash or a number are list items, and text between asterisks is emphasized.

Opening a Markdown file

Choose File, Open and pick the file; the Import dialog shows its kind as Markdown. The file is read the way an HTML file is: headings become the heading styles h1. to h6., paragraphs become paragraphs, bullet and numbered lists become list items, emphasis becomes the emphasis codes, inline and fenced code becomes computer braille, links become hyperlinks, tables become table codes, block quotes and horizontal rules are kept, and a picture is replaced by its alternative text. Edit, Insert File takes a Markdown file into the open document the same way.

Saving as Markdown

Choose File, Save As and the type Markdown (*.md). A print document is written with its headings, paragraphs, lists, emphasis, code, links and tables as Markdown. A braille document is written as its laid-out pages, each page a block of Unicode braille, so the cells show on any screen or display that has a braille font.

Large files

A Markdown file the size of a textbook opens as one document. Opening, translating and laying out a book of fifteen hundred pages takes a few seconds each on an ordinary computer; the program keeps the whole document in memory while it is open.
