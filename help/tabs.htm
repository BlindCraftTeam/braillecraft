Document tabs

Every open document has a tab across the top of the BrailleCraft window, as a web browser shows its pages. The tab carries the document's name and kind, for example Untitled Print Document 1 or chapter.dxb -- Braille Document; the window title repeats the name of the document you are in. The list at the end of the View menu names the open documents in the same order as the tabs, numbered, with the one you are in checked.

Moving between documents

  • Ctrl+Tab goes to the next document and Ctrl+Shift+Tab to the previous one, around the row.
  • Choose a document from the end of the View menu, or press its number there.
  • Click its tab, or move to the tab row with the keyboard and press the Left and Right arrows.

Closing a document

Ctrl+W (Cmd+W on macOS) closes the document you are in, as File, Close does; a document with changes asks whether to save them first. On Linux and Windows each tab has a close button after its name; a middle click on a tab closes it on every system.

Reordering the tabs

Drag a tab along the row to move it. From the keyboard, Ctrl+Shift+Page Up moves the document you are in one place to the left and Ctrl+Shift+Page Down one place to the right. The View menu's list follows the new order.

Screen readers

The tab row is the system's tab control, so a screen reader reads it as a tab list and announces the selected tab, which names the document you are in. Each tab holds the editing area, the status line and the translated line of its document, as they were in the document window before; the reading keys of the JAWS, NVDA, VoiceOver and Orca scripts work as before.
