BrailleCraft add-on for NVDA

This add-on gives NVDA, in BrailleCraft, what the BrailleCraft JAWS scripts give JAWS. It works in a document window; elsewhere the keys say "not in document window". BrailleCraft's Global, Internationalization, Support UI Automation must be on (it is, unless it was turned off).

Keys

  • Alt+7: the translated line (the print of the line in a braille document; the braille cells in a print document).
  • Alt+8: the current style; twice quickly: the row and column in a table.
  • Alt+9: the location: page, line and column.
  • Alt+0: the document name and the status line.
  • Alt+Comma: the position on the line; twice quickly: the characters to the end of the line.
  • Alt+Period: the characters on the line; twice quickly: the left spaces.
  • Alt+End: the last word on the line.
  • Alt+Semicolon: the review cursor to the start of the translated line, and back to the caret.
  • Alt+U: the speaking level for up and down in a braille document: silent, braille characters, the translated line.
  • Alt+I: the announcements of style changes and skipped lines.
  • Alt+P: the echo for entry in a braille document: as NVDA's typing echo, silent, characters, words, characters and words.
  • Alt+W: the reading of the completed braille word when you press space.
  • Alt+C: whether a braille keyboard is connected.
  • Alt with an arrow key: the table entry moves, with the entry spoken; NVDA+Alt+UpArrow: the current entry.
  • F2, Alt+F3, Control+F8 and Control+H go to BrailleCraft and the new state is announced: six-key entry, the coded or formatted view, the translated line, highlighting.
  • Shift+F3 (Change Case): the changed text is spoken.
  • NVDA+H: this key list; NVDA+Shift+H: troubleshooting notes.

In a braille document

Typed characters and the characters and words the caret moves over are spoken as braille cell names; the page is said when it changes; style changes and skipped lines are announced when turned on. In the coded view of a print document a code is read as "code" and its letters, and a style start or end as "begin style" or "end style" with its name.

Settings

The BrailleCraft page of NVDA's settings (NVDA menu, Preferences, Settings) holds the choices the keys above change, and the others: braille characters spoken as braille signs, requested status information shown on the braille display, print lines read by word in the coded view, the status line used for Unicode values.
