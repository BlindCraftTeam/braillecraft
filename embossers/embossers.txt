# BrailleMaker embosser models.
#
# A model is one or more name lines, each a name in double quotes, optionally followed by an Index firmware version
# or range (V2, V3_early-V3, V5), then its properties between a line { and a line }. A property line is a name
# alone (a flag), name = number, name = "text", name = word, Encoding = "section" (an encoding the model can use;
# the first is its default), a form line
#     Form "id" = width x length ; SinglePage|DoublePage [cell offset] ; max cells x lines ; recommended cells x lines
# (sizes in tenths of an inch; a model with interline print gives BrailleOnly = ... ; ... ; Interline = ... ; ...
# instead of the two pairs), or HardwareDCB / SoftwareDCB followed by a { name = value } block of serial port
# settings. TopMargin, LeftMargin, RightMargin and BottomMargin (tenths of a millimetre) apply to the forms after
# them. Property names are matched without regard to case. Lines starting with # are comments.
#
# A file myembossers.txt beside this one may hold models of the same names; they replace these.
